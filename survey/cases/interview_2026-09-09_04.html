二、核心一手信息与关键发现

Pagsmile（巴西团队 + 北京 Victor）

1. 机构画像与产品体系

  • Pagsmile 为巴西持牌支付机构，与巴西央行直连；两大产品线：巴西本地收单（PIX、信用卡、Boleto，信用卡侧即为收单机构 acquirer，对标 Cielo）与 PagHub 跨境网关——一次集成覆盖多个国家 150–200 种支付方式。
  • 团队结构：技术团队全部在北京（约 100 人），为核心；巴西本地 7 人；Victor（信用卡负责人）驻北京办公室；Armando 为巴西高级集成专家；Marlon 为管理层（线上接入）。所有拉美集成（墨西哥、哥伦比亚、智利）统一由巴西团队负责——“拉美业务都走巴西”。
  • 客户侧已集成多家中资公司；支持渠道含微信（已与我方建群，并拉 Victor 入群）、Slack、WhatsApp、Telegram，7×24 支持。
  • 集成承诺：沙箱密钥 1 小时内可发、可与我方商务谈判并行启动技术对接；API 对接约 1 个工作日，从商务接触到完全集成上线约 1 周。

2. 进入巴西的合规路径（受访方系统讲解）

  • 本地路径：必须有巴西本地实体 + CNPJ 税号（一切的前提——开银行账户、本地收单均强制要求）；设立实体通常需本地律师/会计师等代理机构代办；若收购本地公司则自带 CNPJ，可直接满足要求。Pagsmile 受央行监管，服务的前提是客户有本地实体。
  • 跨境路径（无 CNPJ 也可做）：跨境卡收单——在巴西收款、换汇后直接汇至中国或其他国家账户，Pagsmile 已有其他客户照此运行；是否可行取决于资金体量。
  • 巴西与全球业务“完全不同”：其他国家或可用集团自有公司，唯独巴西受税号与央行监管约束，是单独一套规则。
  • 受访方主动提出：可为我方出具进入巴西的分步指引（step by step），供报总部决策。

3. 巴西支付市场结构（受访方口径，数字多为其口头估计）

  • 卡组织：Visa + Mastercard 线上份额合计约 99%；Mastercard 近期在巴西超过 Visa——因为 Nubank（巴西最大零售银行之一）只发 Mastercard 卡，全球仅 3–4 个国家 Mastercard 份额高于 Visa。
  • 支付方式占比（整体市场）：信用卡约 50–55%、借记卡约 10%、PIX 约 12–15%（受访方认为到不了 18%）；旅游场景信用卡占比高达 89%–95%，PIX 约 10%——因旅游客单价高，更依赖信用卡分期。
  • 分期（installments）是巴西标配：旅游消费普遍分 10/12 期，最长可达 21 期；与欧美近年流行的 BNPL 不同，巴西分期已有数十年历史。
  • 关键洞察：约 90% 巴西人的信用卡额度已被既有分期占用，仅剩约 10% 额度可用于新消费——“巴西人想旅行但没钱，只能靠信用支付”，因此信用类产品是转化率抓手；Decolar 等平台均已提供信用产品。
  • 信用支付产品形态：Boleto（带条形码的银行付款单，过去网点缴、现可 PIX 缴，称 Boleto PIX）可做“重新生成付款单”式的先买后付；Pagsmile 下月将上线基于 PIX 的信用/先买后付产品。
  • 现金已基本消失：自 PIX 上线后（录音口径 2018 年，存疑）巴西快速去现金化，餐厅等场景全部刷卡。
  • 国际卡痛点：巴西 POS 机配置只收雷亚尔、餐厅不开美元选项——国际信用卡刷美元在巴西非常困难，不是银行不受理而是终端配置问题；巴西“还不是一个高度互联的国家”。

4. 定价逻辑与费率

  • 信用卡成本核心为 interchange（交换费），公开可查（Visa/Mastercard 官方费率表链接已发我方微信群）；interchange 取决于两个变量：商户所属行业（旅游）与消费者卡种——黑卡/高端卡费率高、标准卡费率低。
  • 受访方明确不愿当场报价：客户卡种结构不明会导致报价失真（“今天报价、两个月后亏本就得改口”），需先了解我方消费者构成才能给出准确价格；同时强调其各支付方式定价“非常有竞争力”。
  • 应收款提前结算（anticipation）：客户分 10 期、商户可分 3 期提前收到全款（费率表述转写含糊，需书面确认）。

5. 产品演示（屏幕共享，收款 + 代付双后台）

  • 收款 dashboard：按国家分应用；可创建支付链接直发客户，或 API 集成（client ID + secret key）；提供白标 checkout 页（挂我方品牌，客户选卡/PIX 支付，完成后推送状态）；支持回调至我方自有支付管理系统、后台直接退款、交易逐笔跟踪；测试环境 + 测试数据可全量开放。
  • 代付（payout）dashboard：收款资金可配置自动划至代付后台、币种任选（美元/人民币等），即时/按日/按小时结算可选；支持批量代付（上传文件，如给航司集中付款）、付款回单下载、Slack/Telegram 自动化取单；双后台均支持多账号多权限分级。
  • B2B 与 B2C 同轨：可为 B2B 单独建应用/支付通道，本质是两家企业间的结算型交易。
  • 能力缺口（我方提问验证）：订单级分账（机票+保险合并支付、后台拆分付给多方）无现成产品——巴西此类税费/保险通常按月/按周结算、不挂订单；受访方表示 API 有 flex fields 可探索，愿意研究并为我方定制开发，数日内给方案思路。

四、初步商机识别（OTA / 非 OTA）

初步商机识别

OTA 机会

  • 跨境收单快速落地（无本地主体即可跑）：PagHub 一次集成 150–200 种支付方式 + 收款换汇回国，可支撑“先跨境跑业务、后设本地主体”的两步走｜优先级高，可作为进入巴西的第一步。
  • 本地收单 + 分期 + 信用产品：取得 CNPJ（新设或收购）后接入 PIX/信用卡分期/即将上线的 PIX BNPL——分期是巴西大众旅游市场的钥匙｜优先级高。
  • 商户金融（应收款提前结算）：分 10 期卖、3 期收款，缓解长账期对营运资金的占用｜优先级中高（本地收单配套）。

非 OTA 机会（对标集团战略）

  • 供应链代付与汇兑：批量代付航司/酒店等供应商、多币种（含人民币）自动结算回国、付款回单齐备｜优先级中高，与 OTA 收单打包谈判。
  • B2B 结算通道：为供应商付款单独建应用/通道，权限分级完善｜优先级中。
  • 定制开发合作：订单级分账（机+保合并支付）若落地，可把国内成熟模式输出为巴西市场差异化能力｜优先级中低，待对方可行性回复。

  • 财务/投资：跨境收单与本地收单两条路径的成本对比测算（含 interchange 按卡种结构的情景分析）。
  • 商旅：维护已建立的微信对接群（含 Victor/Armando），跟进下次会议（对方提及 Liu 参加）。
